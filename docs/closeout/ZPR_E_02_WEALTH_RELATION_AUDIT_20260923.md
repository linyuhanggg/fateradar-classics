## 可实现合同所需的最小字段，而非已登记键名

现有 `gan`、`canggan`、`shishen` 只有本命层与柱位；一个柱位同时可能有透干和多枚藏干，`shishen@pillar` 不能把某枚十神稳定连接到哪一枚干，更不能把「食→财」「财→官」「官→劫」串成同一条有序作用链。`geju` 是单值名；现有 `ZPR-P1-01`、`ZPR-P1-02` 可并存入口，不能用单值 `geju.mode` 覆盖它们。`geju.execution.supports.purpose` 是产品报告文字，不是 Classics 已登记 FactKey。

正式互通合同至少须为**每一条月令入口**保存下列记录；在全部值域和反证边界裁定前，以下仅是接口需求，不应添加到 `fact-vocab.json` 或 P1 manifest：

| 槽位 | 必须确定的机器语义 |
| --- | --- |
| `entryId / entryStatus` | 本命月令来源；`candidate / adopted / rejected / unknown`，保留多入口并存。只有本格已经裁为所用，才可给该入口输出其逐格作用。 |
| `actorRef / targetRef` | 稳定身份至少含 `layer=本命`、`pillar`、`gan`、`天干/藏干`、藏干角色及入口 ID；例如 `丙@month:天干 → 戊@month:藏干` 与 `丙@time:天干 → 戊@year:天干` 不能混作一条。 |
| `relation / effect` | 分列 `食神生财`、`财生官`、`官制劫`；每条需 `observed / effective / blocked / unknown` 及证据。`observed` 只证字面与五行方向，非 `effective`。 |
| `route / interference` | 已采用食路线还是官路线；官露、伤官、七煞、印制食、财印相碍、官伤／官合、比劫夺财及月气变用，逐项记录作用对象、反证及未决。L617 的并路干扰不能被两条各自的局部真值覆盖。 |
| `protection` | `potential`（财生官但当前无夺财威胁）、`active`（有劫且官确实制之）、`blocked`、`unknown`；L402 的实际救应须具名比劫、官及二者作用，不能从官透推断。 |
| `coverage` | 记录四柱天干、月藏、其它藏干、合冲刑会和具体关系是否完整；缺位是未知，完备扫描确无才可判某分支不满足。未触发食／官分支与整条教义「不满足」不同。 |

已有谓词语言的 `scope` 仅有 `layer/pillar/...` 等固定字段，且 `all_of.same` 不能跨事实绑定特定干与藏干的 `actorRef`、`targetRef`、入口 ID。若新增一个扁平布尔键直接报「食生财=true」，会把上述路线取舍、因果方向和反证藏在生产者内部，难以独立复核。需先定关系实例与谓词绑定/外部评价的版本合同，再命名正式 FactKey。

## 最小解锁样盘和裁决问题

1. **食路线正／反／缺位**：从真实公历出生时间导出一盘已裁定财入口、透食而不露官、食与目标财身份明确、身强和食印干扰已分别判定的正例；另以当前 1988-04-09 03:20 盘由独立评审裁定其“食生财关系观察”与“财用食生路线/成格”是否应分层不同判语，不能拿 Product `bearing=不满足` 代替古籍裁决；同盘删除食干、月藏或入口 ID 应按各自缺项返回未知。原书 L996 杨侍郎四柱可作来源例，不是已核公历真盘。
2. **官路线无劫／有劫／受阻**：以 1980-07-11 11:20 盘固定“财生官已观察、未发生制劫”的边界；再给真实日期财入口 + 可作用官 + 可作用劫的盘，并对照官弱于劫、官合绊或官遭伤的反例，逐条区分 `potential`、`active`、`blocked`、`unknown`。原书 L991 葛参政四柱仅作来源例，不冒充已核真实日期。
3. **并路冲突**：提供完整真盘同时有财入口、有效食及官透的对照，裁定 L617「露食则杂」何时生效，及 L996「不露官」是否阻断食路线；须能证明位置／受制／合绊改变结果，而不只增删十神名称。
4. **整体 ZPR-E-02 三态**：先定义这一财格分支的反例是否仅表示“某一路线未成／另一路线待核”，再覆盖官、印、食及煞、伤、刃、劫诸入口，建禄月劫另取和多入口取舍。`fail_when=没有月令用神可分顺逆` 目前无法由单一戊透失败或某一关系失效证明；不得把上面的窄结构三态记作 E-02 已严格三态验收。
