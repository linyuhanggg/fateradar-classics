## 2. 裁决原则

1. **以原文为准**。每条结论都钉到行号，引文逐字，字形照录（嵗／歳、尅、㓙等异体不改）。
2. **可推广的前提**：原文先立通则、再用“如”举例，且同段另有通则性表述时，可推广到同构情形；字面例仍作为独立锚点样盘，将来如需收窄推广范围，不必重做。
3. **原文没说清就判信息不足**。只有能写成确定条件时才裁决；写不成的一律“信息不足”，不补口诀、常识或算法。
4. **L1 不以 L2 为前提**。L1 结论的每个输入都必须是结构事实或本文定义的语义事实。凡要以喜忌、用神、日主旺衰为前提的分支，一律不产出 L1；这些在产品中是 L2 流派口径（`favorable-synthesis`、`strength-score`）。
5. **同书两处定义相反**：取两处一致的部分；不一致的部分判信息不足。
6. **跨书分歧只记录，不合并**。每条 L1 结论只代表所引那一本书的说法，用户可见说明里写明书名。

## 4. SANMINGTONGH-010：日犯岁君与救应

原文（《三命通会·論太嵗》，`sources/fulltext/bazi/sanming-tonghui/fulltext.md`）：

- L1081：“日犯歳君災殃必重”；“日犯嵗君如甲日尅戊年為偏財譬臣弑其君子弑其父深為不利”。
- L1082：“四柱元有庚申金或大運中亦有将甲木制伏純粹不能尅戊土為有救經云戊巳愁逢甲乙干頭湏要庚辛是也”；“如大運并四柱中有一癸字與戊相合為有情經云壬以癸妹配戊凶為吉兆是也”；“若二字俱全其年凶反為吉有一字者㐫半二字俱無㓙莫能觧”。
- L1086：“柱中無庚辛巳酉丑金局制木丙丁火局焚木者太凶”。
- L1087：“大抵日犯嵗君在五陽干則重在五隂干則輕若日干是天月徳太嵗是用神則無咎而反有獲”。

### 裁决 010-1　日犯岁君的范围（推广到十干）

- **疑点**：原文只举甲日克戊年；此前草稿拒绝推广。
- **裁决**：推广。L1081 先立通则“日犯歳君災殃必重”，再以“如”引出甲戊之例；L1087“在五陽干則重在五隂干則輕”说明通则覆盖阴阳十干；L1082 所引经文“戊巳愁逢甲乙”也不只指甲戊。
- **可执行条件**：日犯岁君 = 本命日干的五行克所选流年天干的五行，且两干不构成十干合。
- **十干合**（甲日己年、丙日辛年、戊日癸年、庚日乙年、壬日丁年，即阳干克其所合的阴干）：克与合并存，原文未说何者为主 → **信息不足**。
- 日干或流年干缺失、冲突 → 信息不足；不相克 → 否。
- 甲日戊年保留为字面锚点样盘，与推广样盘分开登记。

### 裁决 010-2　有救（制住日干）

- **疑点**：“庚申金”是指同柱庚申，还是任一金？“制伏純粹”有无门槛？L1086 又把“丙丁火局焚木”列为免于“太凶”的条件，而丙丁同时克庚辛。
- **裁决**：以天干为准。L1082 所引经文明言“干頭湏要庚辛”。设 C 为克日干的五行（官杀之行），F 为日干所生的五行（食伤之行，在五行里正好克 C）。按取样干判：

| 取样干中的情况 | 有救 | 理由 |
|---|---|---|
| 有 C，无 F | 成立 | 经文“干頭湏要庚辛”；无 F 即无克制救神之物，可视为“純粹” |
| 有 C，也有 F | 信息不足 | F 克 C，“純粹”与否原文未定 |
| 无 C，有 F | 信息不足 | L1086 以 F（丙丁火局焚木）作减凶条件，但 L1082 的“有救”只举金制；F 单独是否算“有救”原文未定 |
| 无 C、无 F，但取样支中有本气为 C 的地支 | 信息不足 | 单独地支之金能否“制伏純粹”原文未定 |
| 以上都没有 | 不成立 | — |

- 所选年没有有效大运 → 信息不足（大运干可能带来 C 或 F）。
- 非日犯岁君 → 不适用。

### 裁决 010-3　有情（合住岁干）

- **疑点**：是否要求合化、得令、不被冲破？几个癸算数？
- **裁决**：设 P 为所选流年天干的十干合对象（戊年 P 为癸；一般为 甲↔己、乙↔庚、丙↔辛、丁↔壬、戊↔癸）。按取样干判：

| 取样干中的情况 | 有情 | 理由 |
|---|---|---|
| P 恰好一个，且取样干中没有与流年同干者 | 成立 | L1082“有一癸字與戊相合為有情” |
| P 两个或以上 | 信息不足 | 争合；原文只说“一癸” |
| P 恰好一个，但取样干中另有与流年同干者 | 信息不足 | 这个 P 可能先合本命或大运的同干 |
| 没有 P | 不成立 | — |

- 不要求合化、得令，不看冲破：原文只说“相合為有情”，没有设化气条件，另加即属补造。
- 所选年没有有效大运 → 信息不足；非日犯岁君 → 不适用。

### 裁决 010-4　阶梯与吉凶

- 两项都成立 → **吉**（“其年凶反為吉”）。
- 恰好一项成立 → **凶**，凶势减半（“有一字者㐫半”）。
- 两项都不成立 → **凶**（“二字俱無㓙莫能觧”）。
- 只要有一项确定不成立，就可以判凶：另一项无论成立与否，结果都在“凶半／凶莫能解”之内。判吉则必须两项都成立。其余组合（有一项信息不足、另一项成立或信息不足）→ 信息不足。

### 裁决 010-5　天月德例外

- 原文 L1087：“若日干是天月徳太嵗是用神則無咎而反有獲”。
- 用神在本产品属 L2 流派口径，不能作为 L1 的前提（原则 4）。因此：日干是本命月的天德或月德时，010 在该盘**不产出 L1**；日干不是天德、月德时，这个例外不可能成立，010 照常判。
- 天德为卦位（坤、乾、艮、巽）的月份，日干不可能是天德，只查月德。

### 裁决 010-6　阴阳轻重与跨书分歧

- L1087“五陽干則重，五隂干則輕”只写进说明，不改变吉凶方向。
- 《滴天髓阐微·岁运》L13432“日犯岁君，日主旺相无咎，日主休囚必凶”以日主旺衰为条件，与本书的救应阶梯不同，而且旺衰在本产品属 L2。只记录分歧，不合并；010 的 L1 结论只代表《三命通会》的说法。
- 本节未采纳：L1083 真太岁、征太岁；L1085–L1087 两个命例；L1087 天冲地击、太岁克当生时。这些不在本次合同之内。

## 5. SANMINGTONGH-011：岁运并临

原文：《論太嵗》L1084“又如甲子流年又是甲子運謂之嵗運并臨獨羊刃七煞為凶財官印綬亦吉經云嵗運并臨災殃立至此指羊刃言也”。

### 裁决 011-1　并临的定义

- 并临 = 所选流年干支与该年有效大运干支完全相同，即产品现有 `suiyun_binglin=是`。
- 只取 L1084 这一句。徐注 L8893–L8894 的“同支异干”并临，以及《論陽刃》L3459–L3461 的“岁运再遇羊刃”，是另外两段、另一取用层次，不并入。L1084 后半的“日年相併”（日柱与太岁相同）排除。

### 裁决 011-2　羊刃、七煞、财官印绶的认定

分类对象是并临的那组干支（即该年流年干支），对本命日干取十神或刃：

- **七煞**：并临天干是日干的七杀（偏官）。
- **羊刃**：同书对“刃”有三种说法，互不一致：
  - 《論羊刃》L1620–L1623 按“祿前一辰”给十干（含阴干）都定了刃；
  - 《論陽刃》L3458 说“惟甲丙戊庚壬五陽干有刃乙丁己辛癸五陰干無刃”，同句又说“惟見傷官與陽刃同禍故乙見丙亦謂之刃”；
  - L3459 再分“刃有三”：劫財刃（“甲見乙”，天干劫财）、護禄刃（“甲見卯”，地支）、背禄刃（“乙丙”，阴干见伤官）。
  - 裁决：三处一致的只有**阳干地支之刃**（甲卯、丙午、戊午、庚酉、壬子）→ 刃**确定**。
  - 以下情形在三处之间说法相反或只见一处 → 刃**不确定**：阴干地支落在祿前一辰（乙辰、丁未、己未、辛戌、癸丑）；并临天干是日干的劫财；阴干日主见并临天干为伤官。
  - 其余 → 无刃。
- **财官印绶**：并临天干是日干的正财、偏财、正官或正印。偏印不算：L3316“倒食即偏印之謂”，本书另立倒食一门，不作印绶。

### 裁决 011-3　类别与优先

| 情况 | 类别 |
|---|---|
| 刃确定或有煞，且天干不属财官印绶 | 羊刃七杀 |
| 刃确定，且天干属财官印绶（如甲日并临己卯、辛卯、癸卯） | 信息不足：原文“獨羊刃七煞為凶”与“財官印綬亦吉”同时成立，未说先后 |
| 刃不确定，天干为七杀 | 羊刃七杀（有煞已足以判凶） |
| 刃不确定，天干不是七杀 | 信息不足 |
| 无刃无煞，天干属财官印绶 | 财官印绶 |
| 无刃无煞，天干为比肩、食神、偏印，或阳干日主见伤官 | 其他（原文没说吉凶，不产出 L1） |
| 并临=否 | 不适用 |
| 并临信息不足（无有效大运等），或日干缺失 | 信息不足 |

注：劫财天干一律属“刃不确定”，因此不会落入“其他”。

### 裁决 011-4　吉凶

- 羊刃七杀 → **凶**（“獨羊刃七煞為凶”“此指羊刃言也”）。
- 财官印绶 → **吉**（“財官印綬亦吉”）。
- 不要求命局喜忌：L1084 直接按类别给出吉凶，没有设喜忌条件；徐注所说“有用”属于另一段，不合并。2026-09-22 请求中的 `natal_favorable_context` 因此不是 011 的输入。

## 6. DITIANSUICHA-051：岁运喜忌、盖头截脚——裁决为不产出 L1

原文（《滴天髓阐微·二十八、岁运》，`sources/fulltext/bazi/ditiansui-chanwei/fulltext.md`）：L13402“必先明一日主，配合七字，权其轻重，看喜行行何运，忌行何运”；L13416–L13428 盖头、截脚全部以“喜某运”为前提；L13421“盖干头喜支，运以重支”；L13432 以日主旺相、休囚定日犯岁君吉凶。

- **裁决**：051 **不具备 L1 条件**，这是裁决，不是暂缓。
- **理由**：051 的每一个分支都以喜忌或日主旺衰为前提。原文要求“配合七字，权其轻重”，但没有给出可执行的算法；在本产品中，喜忌（`favorable-synthesis`）和旺衰（`strength-score`）都是 L2 流派口径。按原则 4，L1 结论不得以 L2 为前提。除非将来另立一份“喜用神本身”的 L1 合同（相当于裁决整套用神理论，不在本次委托范围内），051 都只能以 L2 呈现。
- **后果**：`yongshen_effective`、`jishen_empowered` 维持 pending；产品的大运、流年方向继续由 L2 流派口径覆盖，并照常标注流派标签。
- 盖头、截脚本身是纯干支结构（天干克地支、地支克天干），将来可以作为不含吉凶的结构事实另行交付，本次不做。
