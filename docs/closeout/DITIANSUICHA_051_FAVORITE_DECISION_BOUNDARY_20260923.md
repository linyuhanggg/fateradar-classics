# 051 上游喜行五行裁决边界

状态：`favorite_luck_element_decision_record` 仍是**请求名称**，不是已采纳 FactKey、事实生产器或已裁决结果。本审计建立最小可审计记录的准入条件；不改 `DITIANSUICHA-051`、P1 manifest 或产品事实。

## 原文允许的条件分支

- 《八格》任氏曰 [L2663](../../sources/fulltext/bazi/ditiansui-chanwei/fulltext.md#L2663) 先核月令、透干、司令，禄刃另寻用；月支或候选干不能单独定取用。
- 《体用》[L2942–2945](../../sources/fulltext/bazi/ditiansui-chanwei/fulltext.md#L2942) 明言旺而不可抑时反宜扶、弱而不可扶时反宜抑；[L2967](../../sources/fulltext/bazi/ditiansui-chanwei/fulltext.md#L2967) 又有原局用神受合冲阻隔后“随岁运取用”。固定 `rizhu_strength` 档位或固定本命喜行不覆盖这些分支。
- 《衰旺》[L3203–3220](../../sources/fulltext/bazi/ditiansui-chanwei/fulltext.md#L3203) 说明得令未必旺、失令未必弱，根气与刑冲能改变判断。强弱需要完整结构证据，不能只按月份、数量或现代分数作原文同义替换。
- 《喜神》[L7315–7317](../../sources/fulltext/bazi/ditiansui-chanwei/fulltext.md#L7315) 的同一条件“戊日寅月、寅中甲木为用”还要分元神厚、薄：前者取壬癸亥子之水为喜，后者取丙丁巳午之火为喜；同段另有身弱改用寅中丙火的入口。它是**条件规则原型**，并未给出现有 `rizhu_strength` 档位到“厚／薄”的判据。两分支不能由“戊日寅月”或“用木”直接择一。
- 《闲神》[L8979–8999](../../sources/fulltext/bazi/ditiansui-chanwei/fulltext.md#L8979) 区分喜、忌、仇、闲；同为“用木”，有余时火喜、金忌、水仇、土闲，不足时水喜、土忌、金仇、火闲。“未入喜行集合”不是显式忌或不喜的证据。

## 最小决定记录与三态

一份将来可消费的逐五行记录至少要包含：`chartRef` 与四柱/节气证据、采用的注家和原文行锚、取用路线及其适用条件、旺衰/从格与元神厚薄的可复核判断、被排除路线及证据、当前所选年 `scope.year`（或明示本命基线怎样延续至该年）、五行逐项分类、冲突处理与未决项。`sourceRuleOrRoute` 不能只写“扶抑”之名；`evidence` 不能只有候选干或自由文本喜忌。多个喜行可并存，不能强制单值。

对某五行的**裁决记录本身**：

| 状态 | 最小条件 | 禁止推出 |
|---|---|---|
| 满足／明确喜行 | 所选范围内采纳路线，逐五行给出支持证据，所有会改变该五行判断的其它入口已排除或有可复核冲突裁决。 | 用神已得力、该年吉凶。 |
| 不满足／明确非喜行 | 同样的完整范围与路线证据，且有该五行不属喜行的**显式**裁决；须说明是忌、仇、闲还是仅此路线不取。 | 不能从“未列入喜行”自动写成忌神或 051 作用失败。 |
| 信息不足 | 缺来源、原局事实、厚薄/从格判据、年 scope、显式逐值分类，或并存路线冲突未决。 | 不得把候选路线的 `adopted`（只为展示）当作来源已裁决。 |

这些是**准入条件**，不是一个已有的自动取用算法。L7315–7317 提供厚／薄条件分岔，L8998–8999 提供有余／不足时的喜、忌、仇、闲区别；它们没有为任一共享真实日期盘完成所有前置裁决。即使将来确认喜行，盖头／截脚例表仍只作条件形态，不能直接计算作用；见[独立形态合同](./DITIANSUICHA_051_LISTED_SHAPE_CONTRACT_20260923.md)。
