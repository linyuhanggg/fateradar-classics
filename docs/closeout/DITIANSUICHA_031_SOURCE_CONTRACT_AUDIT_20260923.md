# DITIANSUICHA-031 来源合同审计（2026-09-23）

## 结论

1951-09-26 23:20 上海是可复算的四正双冲结构候选，但不是《滴天髓阐微》所载命例的公历生日。现存 source case 只记录四柱 `辛卯／丁酉／庚午／丙子`，并明确没有公历生日、出生地、时制或起运资料；不能以候选日期补写原例身份。

来源不止支持这一张命例。第三十三章“震兑”给出可推广的条件式分析框架：先分辨主之所喜、金木强弱与震兑位置，再依季节选择攻、成、润、从、暖等路线。但它没有支持“任见卯、酉便按同一作用处理”。当前 `DITIANSUICHA-031` 仍为 `verified: false`；它只以 L101 锚定“卯酉为震兑”，而适用谓词只要求盘内有卯、有酉，缺少主客与柱位、日主角色、季节、气势、藏干及路线条件。因此本审计不采纳或修改该规则，不新增正式 FactKey，也不导入产品。

## 来源证据与范围

《知命》L96–104 是一张特定四柱的论断。前文表列四柱见 L74–80；影印与既有 source-case 注记将其校为 `辛卯／丁酉／庚午／丙子`。原文明确写出“支全四正”，随后说“五行无土，虽诞秋令，不作旺论”，再逐句解释子午冲如何抑火、卯酉冲如何制木，并以“制伏得宜”收束。这里能确认的是作者对这个完整组合的解释，不能单独推出每个卯酉冲或四正盘都有同一效果。

当前 case registry `ditiansui-chanwei:L0096-L0104` 的 `inputBasis` 是 `four-pillars`，`unavailable` 包含公历生日、交节后天数、出生地与时制、起运，且 `verified` 仍为 false。其备注还提示电子全文 L80 将时柱丙子与首运丙申粘连；不要把运表误并为第五柱或由运表补出原例生时。

第三十三章 L6157–6187 才提供较广的震兑方法：

- L6157–6169 区分震、兑何者为主，要求根据主之所喜决定攻、备、是否去除或不可助对方；L6166–6169 又给出不必去木、金强不可战、春木金盛反可制木等不同情形。
- L6179–6187 列出五种季节路线：春初木嫩金坚用火攻，仲春木旺金衰用土成，夏木泄金燥用水润，秋木凋金锐用土从，冬木衰金寒用火暖；末句要求观金木之趋向，不拘内外。

这足以支持“震兑关系需要条件化分析”，也说明“看月令支援”只是过度简化的摘要。它不能直接转成一个由卯酉两个存在事实触发的统一吉凶或作用判断。第三十三章的秋令路线说的是“秋令之木”；1951 候选日主为庚金，不可把它机械套入该路线。L96–104 的庚日四正命例与第三十三章的甲木季节命例应分别建模。

另有一个必须先裁定的术语边界：候选四柱的八个表面干支没有戊己天干，也没有辰戌丑未地支；但午支藏己。L11 将支中所藏列作人元。因此 L98 的“五行无土”究竟只按表面八字计、指没有显露或有力之土，还是另有特定气势含义，原文没有定义。当前不得将 `earth_absent=true` 注册为确定谓词。
