## 真盘裁决与最小缺口

共享 [50 盘 fixture](../../tools/reports/facts-sample.json) 中十个 `caseP1_010_*` 的输入投影已固定在[局部合同](SANMINGTONGH_010_L1082_BRANCH_AUDIT_20260923.json)：八盘 2018 年满足入口，`wrong_day@2018` 与 `wrong_year@2017` 不适用。`both@2018` 的两条 L1082 局部支路都满足，局部阶梯为“凶反为吉”；`same_only@2018` 庚申支路满足、具名癸戊支路不满足，局部阶梯为“凶半”。`split_only` 证明跨柱庚／申不可拼成庚申；缺运、冲突、多癸、其它年份均按各自 scope 保持未知或不适用。**全章作用仍为零个裁定正例、零个裁定反例**：L1086–1087 和 L9697 的分支没有完成合参。

**最小下一裁决**转为 L1082 的独立大运支路：当所选年有效大运没有本命同柱庚申时，原文说何种可观察条件足以证明“将甲木制伏纯粹不能克戊土”，又何种完整输入能证明该条件不成立？提交者须给来源段落／明确定义、原局与选定年运输入及至少一张有效、一张无效、缺键／冲突未知盘；若原文不支持可执行阈值，应正式确认该支路对产品恒为 `undetermined`，而非虚构庚辛计数或强弱门槛。即使回答了这项，也仍须审定 L1086–1087、L9697 的作用及优先级。

## 可消费边界与尚不能填写的字段

本轮复核国图卷二影印 PDF [第 121 页（原印四三）](../../sources/facsimile/other/sanming-tonghui/NLC416-13jh000156-94145.pdf#page=121)、[第 122 页（原印四四）](../../sources/facsimile/other/sanming-tonghui/NLC416-13jh000156-94145.pdf#page=122)及[第 125 页（原印四七）](../../sources/facsimile/other/sanming-tonghui/NLC416-13jh000156-94145.pdf#page=125)：前两页确有 L1082 的两项阶梯、L1086 的后续排除句及 L1087 的例外；第 125 页的“无情之合”在十干合取象段。L1086 紧接的两则命例分别是戊日遇壬年、壬日遇丙年，**均不是甲日遇戊年**，不能充当本例有救／无救的正反标签。

消费方目前只可接收已交付的 `SANMINGTONGH-P1-010A` 甲日／所选戊年入口，以及来源限定的同柱庚申、一癸戊合和 L1086–1087 中性观察。完整 010 没有获准 FactKey：`rescue_condition ∈ {成立, 不成立, 信息不足}` 只是请求值域，缺少“成立”到底指任一救应、两项俱全或含后续例外的定义；`transit_effect_semantics` 更无命局作用和主题映射。完整作用的阈值、优先级及可产 `ruled_out` 的穷尽范围均**未定**，不得以默认阈值、结构数量或 `neither` 填入。假设仅作审计的四个 typed 输入槽与按所选年 `scope.layer=流年, scope.year=Y` 的绑定，见 [JSON](SANMINGTONGH_010_EFFECT_AUDIT_20260923.json)，它们尚不能作为正式输出。

入口三态有独立确定性边界：已知非甲日或已知所选年非戊，即使另一入口键缺失，也判本例“不适用”；两键均无已知反例而缺失则为“信息不足”；同一柱位的 `gan@day` 与 `natal_day_gan` 矛盾、或同年流年干冲突时保留“信息不足”。“不适用”不折成完整救应“不成立”。所选年不得从事实袋中其它戊年补值；当年有效大运也不得从无年份的大运列表挑选。
