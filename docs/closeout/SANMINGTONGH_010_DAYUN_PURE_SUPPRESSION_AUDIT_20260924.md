# 《三命通会》010：大运纯制伏支路维持 `undetermined`

本轮核查没有找到能把 L1082 的大运纯制伏支路变成稳定、可执行判断的原文阈值。因此，对 `caseP1_010_split_only@2018`，本支路正式记为 `undetermined`；不以大运中出现庚辛、五行计数或日主强弱猜出“纯粹制伏”。这一局部结论不解决完整 `SANMINGTONGH-010`：全章作用仍是“信息不足”，规则未采纳、未验证。

## 原文给了什么、没有给什么

[《论太岁》L1082](../../sources/fulltext/bazi/sanming-tonghui/fulltext.md#L1082)在“甲日尅戊年”例中，以“或”另列大运支路：“将甲木制伏纯粹，不能克戊土，为有救”。[HY1521 L4914–4916](../../sources/normalized/shidianguji/HY1521/text.md#L4914)和 [SK1610 L5177–5179](../../sources/normalized/shidianguji/SK1610/text.md#L5177)的断句互证这两个分支：本命四柱原有庚申，或大运纯粹制伏甲木到不能克戊。它们支持条件句的读法，却没有给出要读哪些大运／原局事实、多少力量才算“纯粹”、怎样排除其它克制或生扶，也没有定义充分的反例。这里写的是作用结果，不是计算配方。

同书其它材料也没有补成这个阈值。《五行精纪》类木论 [L687–691](../../sources/fulltext/bazi/sanming-tonghui/fulltext.md#L687)按干支关系谈活木、受克、自死、死木，并叙述金、火、水的相互作用；[《论天干阴阳生死》L740–743](../../sources/fulltext/bazi/sanming-tonghui/fulltext.md#L740)继续描述甲木，最后明言须看火、金、水与化合，“不可执一论”。这些是通用物性与气势讨论，没有指出哪些所选大运组合足以使本例甲木停止克戊。

偏官／七煞部分也不能直接移植为 L1082 阈值。[L3084–3090](../../sources/fulltext/bazi/sanming-tonghui/fulltext.md#L3084)明确要求制合生化有太过、不及之别，并举“七煞一处而两三处制伏”可能制伏过度的例子；其语境是偏官／七煞，不是甲日逢戊岁的这条大运支路。其他七煞条目只给格局原则或概括性“宜制伏”，没有建立本句的输入域和真／假边界。跨语境套用这些条件会是新造解释，不是原文阈值。

## 同章后文是限定因素，不是该支路的操作定义

紧接的 [L1085–1086](../../sources/fulltext/bazi/sanming-tonghui/fulltext.md#L1085)另叙甲日戊年、寅卯亥未、再见甲乙及柱中庚辛／金局制木／火局焚木的凶例；该句涉及可见干支及组合的断句和作用次序仍未裁定，不能反推为 L1082 大运支路的充分或穷尽条件。[L1087](../../sources/fulltext/bazi/sanming-tonghui/fulltext.md#L1087)另说日干为天月德且太岁为用神可无咎反有获，但“太岁是用神”没有在本合同中定值，也没有和 L1082 排定优先级。

《太岁忌逢战斗》注释 [L9697–9698](../../sources/fulltext/bazi/sanming-tonghui/fulltext.md#L9697)提到太岁为用神、身旺／身弱、日与运俱犯、五行有救会减轻、天冲地击，以及“六甲生人逢戊岁运死木克死土”的例子和羊刃岁运刑冲。它为完整作用增加了待合参条件，但没有说明如何判定本例大运“纯粹制伏”，也没有给这些条件与 L1082 的优先级。尤其“死木克死土”没有在这两句中给出所选运对本句支路的穷尽真值表。

因此，这些后文与旁论应作为完整 010 的待裁例外／限定保留；不能把它们合并成一个看似确定的纯制伏算法。影印第 121–122 页的视觉复核记录沿用既有 L1082 分支审计；本轮重新核对了来源文本、两份点校见证、PDF 哈希与共享 fixture，没有声称重新做影印视觉复核。机器可读证据和验证入口见 [审计 JSON](SANMINGTONGH_010_DAYUN_PURE_SUPPRESSION_AUDIT_20260924.json) 与 [验证器](../../tools/verify-sanming-010-dayun-pure-suppression-audit.py)。
