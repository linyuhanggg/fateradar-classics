# 《三命通会》010：庚申字面支路与有效制伏分离

裁决限于《论太岁》甲日逢戊岁例的一个来源步骤。国图[卷二影印第 121 页（原印四三）](../../sources/facsimile/other/sanming-tonghui/NLC416-13jh000156-94145.pdf#page=121)右侧行列可直接见“若五行有救……四柱元有庚申金或大運中亦有將甲木制伏純粹不能尅戊土為有救”。原字以“或”列出两个来源支路；[HY1521 L4914–4915](../../sources/normalized/shidianguji/HY1521/text.md#L4914)与 [SK1610 L5177–5178](../../sources/normalized/shidianguji/SK1610/text.md#L5177)的断句也把“本命四柱元有庚申金”与“有效大运纯粹制伏到不能克戊”分开。因此，完整四柱存在任一同柱庚申，即满足 L1082 这一条**局部来源支路**；“制伏纯粹不能克戊”的力量条件只在另一条大运支路上，不能反向变成庚申支路的门槛。

这个判断只确认原文明写的甲日戊岁局部条件，不延伸为“庚申一般都能有效制甲”的通用算法。同书[《论偏官》L3084–3087](../../sources/fulltext/bazi/sanming-tonghui/fulltext.md#L3084)明说制合生化须权太过不及，并举“甲寅……见庚申”而在子辰印局下走“煞生印、印生身”的另一作用路径；它提醒不能把 L1082 的特例抽离语境推广到其它格局，但没有改写本段明示的庚申条件，也不是本段反例。大运支路仍无从已存在的结构字样推得力量标准。

## 用真实盘隔离两层

共享 [`caseP1_010_same_only@2018`](../../tools/reports/facts-sample.json) 是 1980-08-09 11:20 男命，原局 `庚申／甲申／甲寅／庚午`，所选 2018 `戊戌`，有效大运 `丁亥`。因此甲日戊岁入口满足、**本命同柱庚申支路满足**；四柱与有效大运可见干完整且没有癸，故 L1082 具名癸戊支路不满足。本地条件句据此给出“凶半”。这只是本地条件句的投影，**不是全章吉凶或事件结论**。大运纯制伏支路仍不能由丁亥或任何庚辛字样单独判真伪。

独立合同与验证器 [`SANMINGTONGH_010_L1082_BRANCH_AUDIT_20260923.json`](SANMINGTONGH_010_L1082_BRANCH_AUDIT_20260923.json)、[`verify-sanming-010-l1082-branch-audit.py`](../../tools/verify-sanming-010-l1082-branch-audit.py) 把原局具名支路按完整四柱给出 `满足 / 不满足 / 信息不足`，并按所选年过滤；不完整柱、冲突或跨柱拼接均不能给真值。此局部值不进入正式 FactKey、13 条交接规则或六主题解释，也不替大运支路定值。

## 尚缺的最小原始证据

剩余的最小来源裁决是：如何判定另一条“大运中亦有将甲木制伏纯粹不能克戊土”支路。需要该规则采用的原局／所选年有效大运输入、原文允许的制伏充分条件与冲突政策，以及至少一组能核验的有效／无效或未知案例；若同书不提供可执行阈值，应正式保留这一路为 `undetermined`，不能以可见庚辛或五行计数补足。癸戊支路的多癸边界、L1086–1087 后续条件和 L9697 优先级仍须分别裁决。
