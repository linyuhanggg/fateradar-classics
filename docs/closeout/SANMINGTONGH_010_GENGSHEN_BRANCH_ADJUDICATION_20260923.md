# 《三命通会》010：庚申字面支路与有效制伏分离

裁决限于《论太岁》甲日逢戊岁例的一个来源步骤。国图[卷二影印第 121 页（原印四三）](../../sources/facsimile/other/sanming-tonghui/NLC416-13jh000156-94145.pdf#page=121)右侧行列可直接见“若五行有救……四柱元有庚申金或大運中亦有將甲木制伏純粹不能尅戊土為有救”。影印无现代逗号；“亦有”回指庚申金，是最自然的句法读法，而“將甲木制伏……不能尅戊土”接在两个出处之后，描述被称为“有救”的**作用**。这允许单独识别“四柱元有庚申金”这一**具名文字支路**，不允许由字面支路直接定值 `effectiveSuppression=proven`。

这个界限并非只因标点不明。[本书 L1082](../../sources/fulltext/bazi/sanming-tonghui/fulltext.md#L1082)把“制伏纯粹不能克戊”写在“为有救”之前；同书[《论偏官》L3084–3087](../../sources/fulltext/bazi/sanming-tonghui/fulltext.md#L3084)明说制合生化须权太过不及，并给“甲寅……见庚申”而在子辰印局下成为“煞生印、印生身”的另一作用路径。后者不是甲日戊岁直接反例，却足以排除“任何出现庚申都必然有效制甲”的跨语境推理。[HY1521 L4914–4918](../../sources/normalized/shidianguji/HY1521/text.md#L4914)与 [SK1610 L5177–5180](../../sources/normalized/shidianguji/SK1610/text.md#L5177)均在“庚申金”后点断、在“为有救”前保留“制伏／不能克戊”；两份整理本支持识别具名支路，但它们的现代逗点没有给出作用强度、受制或印化的可执行标准。

## 用真实盘隔离两层

共享 [`caseP1_010_same_only@2018`](../../tools/reports/facts-sample.json) 是 1980-08-09 11:20 男命，原局 `庚申／甲申／甲寅／庚午`，所选 2018 `戊戌`，有效大运 `丁亥`。因此甲日戊岁入口满足、**原局同柱庚申字面支路出现**。原局未见癸这条具名线索；但不能据此证明“有情”一项被穷尽排除。该盘还有月甲、日甲、两庚与多申等同时存在，原文没有一套可以由这些结构直接算出“纯粹制伏”的力量、位置、印化及干扰取法。因此本盘 `effectiveSuppression=undetermined`、`affinity=undetermined`，L1082 局部阶梯及全章作用均“信息不足”。这比把庚申当作零证据更精确，也没有冒充作用成立。

新验证器 [`verify-sanming-010-gengshen-branch.py`](../../tools/verify-sanming-010-gengshen-branch.py) 仅给“原局同柱庚申的具名支路”三态：完整同柱证据时 `present`；四柱全可读且均不匹配时 `absent`；缺键或关键同作用域冲突时 `undetermined`。`absent` **只是否定此具名原局支路**，不排除别的庚辛／有效大运制伏路径，更不是“无救”。所选流年入口另核；支路输出不进入正式 FactKey、13 条交接规则或六主题解释。

## 尚缺的最小原始证据

要把此盘的具名支路提升为**有效制伏**，至少需要同一甲日戊岁语境中一则带完整原局及当年大运的原始断例，明确判示“原有庚申但未能制甲”或“虽有别的印化／火制／根气干扰，仍以庚申为有救”，并给可复核的取舍依据；或者同书对这一句作同等明确的逐项释义。另一份只重复相同无标点句子的影印本，不能解决作用标准。现有 L3087 是不同语境的反向路径，足以制止机械充分条件，却不能代替本例的最终作用裁决。戊癸有情、L1086–1087 后续条件和全章优先级仍须分别裁决。
