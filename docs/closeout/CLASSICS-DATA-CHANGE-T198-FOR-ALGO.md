## 2. 「全信息不足恒为 0」是一条**独立校验**

它与死引用扫描（t192）互为独立实现：

- 死引用扫描：谓词的**键**是否在本术样盘里出现过；
- 本报告：求值后是否每张盘都判「信息不足」。

若某条谓词的键真在任何样盘里都没出现，**两个工具都该报出来**。
现在两者同时干净 → 事实层没有「写了键但引擎不产」的漏。测试里**直接交叉调用**两者。

## 3. 中途修正了自己一次口径错误

第一版脚本把**未映射**规则也算进去了——它们的 `applicable_to` 为空，
求值按设计返回「信息不足」，于是报出 **512 条「全信息不足」**。**那个读数是错的。**

改为只算「**带锚 + 有谓词**」的规则后归零。这正是本轮的意义所在：
**先把度量做对，再报数**（与 t182／t183 的「检索盲区伪造查无」是同一类教训）。

## 4. 这个数字该怎么读（不粉饰）

- **58% 有正面演示** ≠ 其余 42% 是错的。它们分两类：
  目录式（60 条）有**结构性自证**（干支序列自证），
  其余 98 条在**若干轮里做过合成盘的定点验证**（每轮交付文档都记了具体合成盘，
  例如 t175 的「三支缺一→不满足」、t188 的「庚压丙→不满足」、t194 的「父母持世→不满足」）。
- 但**必须承认**：那 98 条里，多数只有「在样盘上不成立」这一条机器结论，
  **没有**正面样盘。要让它们全部被正面演示，需要**成批补样盘**（每条一个满足它的输入）。
- 本报告把这件事**量化并公开**，而不是让它躺在「覆盖率 49.9%」后面。
