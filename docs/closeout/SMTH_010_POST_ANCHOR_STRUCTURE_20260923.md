# 《三命通会》010 后续段的结构入口裁决（2026-09-23）

范围仅为 P1 八字六主题的流年入口。此文审 L1085–1087，不修改 `SANMINGTONGH-010` 在 L1080–1083 的既有锚点、`applicable_to`、`verified` 或六主题 manifest；也不把后续段自动并入原规则。原文中的祸福是古籍断语，不是可据这些样盘验证的现实结果。

## 逐句边界

| 来源 | 可核对的入口 | 暂不能据此判定 |
|---|---|---|
| [L1085–1086](../../sources/fulltext/bazi/sanming-tonghui/fulltext.md#L1085) | “假如甲日見戊年”明确限定例子；随后列出寅卯亥未、额外甲乙、庚辛、巳酉丑金局、丙丁火局。可按所选流年、四柱柱位分别记录字面结构。 | “太凶”、金局**制木**、火局**焚木**或完整无救。L1086 为“无庚辛巳酉丑金局制木丙丁火局焚木”的连写，缺优先级、透干／成局／作用条件；不得拆成几个独立的救应充分条件。 |
| [同书 L4061](../../sources/fulltext/bazi/sanming-tonghui/fulltext.md#L4061) | 以“庚辛得巳酉丑金局”“丙丁得寅午戌火局”明确对应两组三支名称，因此可单列“本命三支齐”及已有 `natal_relation` 是否**发出**三合文本。 | 三支齐或关系文本出现，不证明该局在 L1086 语境下有效制木／焚木；两处章节不能无裁决地拼成作用算法。 |
| [L1087](../../sources/fulltext/bazi/sanming-tonghui/fulltext.md#L1087) | “若日干是天月徳太嵗是用神”是另一个有条件的例外入口。可只读记录产品在**日柱**发出的 `天德贵人`、`月德贵人` 标签。 | 原句的“日干是”不等同于任一柱有神煞标签；“太岁是用神”的对象、取得口径和年度作用未定。即使日柱两标签齐全，也不能宣称“无咎而反有获”。 |

L1085 的甲戊例紧接日年相并及诸凶煞段，L1086 又接两则历史命例，L1087 则转为日犯岁君总论及别的例外；不把这些不同层次压成一个新的布尔规则。L1082 的庚申／癸戊两条具名线索与 L1086 的庚辛／金局／火局也不是同一个“二字”集合。尤其[现有 010 裁决](./P1_SEMANTIC_CONTRACT_ADJUDICATION_20260923.md)所说的 `caseP1_010_neither`，仅表示旧两线索未见；该真盘在 L1086 的原始柱干仍见庚。不能由旧诊断的“neither”推导“柱中无庚辛”。

## 中性观察合同

独立校验器 [`tools/audit-smth-010-post-anchor.py`](../../tools/audit-smth-010-post-anchor.py)只检查来源锚点和两仓共享 `tools/reports/facts-sample.json` 中的真实排盘事实。选定年份 `Y` 的本命日干明确不是甲或该年岁干明确不是戊时，入口为“不适用”；两键未足以确定时为“信息不足”；仅甲日戊岁进入观察。本命柱位必须取 `scope.layer=本命` 的 `year/month/day/time`，不能借无年份的大运列表，也不能拿别的流年补缺。

入口内分别记录：四柱中庚辛、丙丁、日柱以外甲乙、寅卯亥未所在柱位；本命四支是否齐见巳酉丑、寅午戌；本命关系事实是否发出对应三合文本；日柱已发出的天德／月德标签。柱干或地支缺失／冲突时，相应全盘枚举与三支齐标记为 `null`，不能当作空列表或 `false`。已发出标签的空列表只表示本次事实中**未发出**，不是天月德命理判否。合同没有 `rescue_condition`、`transit_effect_semantics`、`太岁是用神` 或任何吉凶输出。

| 共享真盘 | 已证的窄观察 | 不得外推 |
|---|---|---|
| `caseP1_010_both@2018` | 本命年／时柱庚；日柱已发出天德、月德。 | 两旧线索和两德标签均不证明完整救应。 |
| `caseP1_010_split_only@2018` | 庚与申跨柱，但年／时柱仍有庚。 | 不得拼成同柱庚申；也不得称柱中无庚辛。 |
| `caseP1_010_luck_gui_only@2018` | 本命月柱丁；有效大运癸另属 L1082 线索。 | 丁字不等于火局焚木。 |
| `caseP1_010_neither@2018` | 年／时柱庚，尽管旧诊断两条具名线索均未见。 | “neither”不是 L1086 的无庚辛。 |
| `caseP1_010_unknown_luck@2018` | 四柱有寅午戌三支，`natal_relation` 发出火局三合文本；选定年有效大运仍缺。 | 火局结构不证明焚木；缺大运不能作完整救应反例。 |
| `cov3_bazi_12` | 四柱有巳酉丑三支并发出金局三合文本，但本命日干为乙。 | 只证明结构探测能识别真盘，不触发甲日戊岁分支。 |
| `caseP1_010_wrong_day@2018`、`wrong_year@2017` | 入口不适用。 | 不偷读错年盘中的戊岁。 |

继续施工的最小缺口是：庚辛干与三合局的有效制木口径、丙丁与火局有效焚木口径、L1086 连写条件的结合／例外次序；以及 L1087 “日干是天月德”和“太岁是用神”的原文对象与正式事实来源。上述口径形成前，L1086 的“太凶”、L1087 的“无咎而反有获”及 L1082 的“凶反为吉／凶半／凶莫能解”均保持未判定。
