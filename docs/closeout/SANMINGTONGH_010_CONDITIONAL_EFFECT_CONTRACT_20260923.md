# 《三命通会》010：甲日戊岁例的条件式作用阶梯

此交付只把《论太岁》[L1081–1083](../../sources/fulltext/bazi/sanming-tonghui/fulltext.md#L1081) 已说出的**条件式步骤**写成可核验合同。完整 `SANMINGTONGH-010` 仍为 `blocked`，`applicable_to=[]`、`verified=false`；本步骤不进入六主题规则包，不把文本中的“吉／凶”当现实事件预测。机器可读定义见[合同 JSON](SANMINGTONGH_010_CONDITIONAL_EFFECT_CONTRACT_20260923.json)。

## 来源范围与输入

入口仅为本命**甲日**遇**所选戊流年**。当生太岁与逐年游行太岁不同；同一事实袋即使含其它戊年，也不能代替所选年份。其它日干／岁干组合是本例“不适用”，不能据此判完整 010 不成立。

来源先把甲木克戊土称作“日犯岁君”，再给两条局部来源输入。《论太岁》[L1082](../../sources/fulltext/bazi/sanming-tonghui/fulltext.md#L1082) 的句法是“本命四柱原有庚申金”**或**“当年大运另将甲木制伏纯粹、不能克戊土”，两者是并列支路；第二支路的力量条件不反向套到第一支路。完整四柱中任一同柱庚申可使本局部“有救”输入 `proven`；四柱不全或矛盾则未知。若本命庚申支路不满足，整体 `有救` 仍未知，因为第二条大运制伏支路尚无可靠的有效性阈值，不能用大运干支中出现庚辛来补造阈值。

同句称四柱或所选年有效大运中“有一癸字与戊相合为有情”。本地合同只把**恰一枚可见癸干**记作 L1082 局部 `有情` 输入；可见癸多于一枚、所选有效大运缺失或冲突时未知；本命四干与所选年有效大运干完整且无癸时，只能判该具名支路不满足。大运必须取该年有效柱，不能从其它年份或无年份的大运列表借值。

来源点校异本支持这个区分：[HY1521](../../sources/normalized/shidianguji/HY1521/text.md#L4914)在“庚申金”后断开，并在“纯粹”之后另断“不能克戊土”；[SK1610](../../sources/normalized/shidianguji/SK1610/text.md#L5177)也把两支用“或”分开。[L1082 独立审计](SANMINGTONGH_010_L1082_BRANCH_AUDIT_20260923.md)逐盘核对本命同柱、选定年大运、额外癸、多年串读和跨柱拼接。它只支持这两条原文支路与 L1082 的局部阶梯，不解开大运制伏阈值及 L1085–1087 后续条件。

产品已有的通用 `named_rescue_evidence_coverage` 仍只给出中性结构扫描，不能替代作用合同。这里的局部分支是另按 L1082 原句建立：完整本命四柱出现同柱庚申，或在四柱与所选年运输入完整时恰有一个可见癸与所选戊配对，才分别满足它所点名的两条局部条件。第一条不需要发明力量阈值；大运纯制伏支路则因为原文要求“纯粹不能克戊”而继续未知。通用[《论十干合》L1118](../../sources/fulltext/bazi/sanming-tonghui/fulltext.md#L1118)的“无情之合”属于另一取象段，不能直接推翻或推广这里的局部称谓；额外癸与争合仍未裁。

同章稍后[L1085–1087](../../sources/fulltext/bazi/sanming-tonghui/fulltext.md#L1085)仍以甲日戊年为例，另列庚辛、巳酉丑金局制木、丙丁火局焚木的排除条件，又说日干为天月德且太岁为用神时“无咎而反有获”。因此 L1082 阶梯只是一道**局部来源步骤**，不是把全章后续条件合参完毕的最终作用；这些后续分支的取法和优先级须独立审定。尤其不能只扫两种具名线索就宣布“零救应”。

## 来源已给出的条件式步骤

下表仅在甲日、所选戊年及两个语义输入**均已独立裁定**时运行。表中的 `ruled_out` 不是“没有看到庚申／癸”的缩写。

| 有救 | 有情 | 原文层的分级 |
|---|---|---|
| `proven` | `proven` | 凶反为吉 |
| `proven` | `ruled_out` | 凶半 |
| `ruled_out` | `proven` | 凶半 |
| `ruled_out` | `ruled_out` | 凶莫能解 |
| 任一 `undetermined` | 任意 | 信息不足 |

“两项、一项、零项”按原文相邻的“有救／有情”两类来实现，是本合同的**局部解释**，只限甲日戊岁例，不向其它干支推广。即使入口已满足，语义输入未裁定也不能输出凶半或凶莫能解。来源出现的“其年反必为财”等判语未纳入此阶梯：其适用及现代六主题映射未裁定。

## 真实盘与验证边界

两仓共享的十个 `caseP1_010_*` 是实际日期排出的事实袋。按 [L1082 分支审计](SANMINGTONGH_010_L1082_BRANCH_AUDIT_20260923.json)，`both@2018` 可计算出**本命同柱庚申支路满足、具名癸戊支路满足、L1082 局部阶梯“凶反为吉”**；`same_only@2018` 可计算出**庚申支路满足、癸戊支路不满足、局部阶梯“凶半”**。这是原文局部条件句的真盘投影，不是全章作用或真实事件结论。

`split_only`、`split_and_gui`、`natal_gui_only`、`luck_gui_only`、`neither`、`unknown_luck` 均满足甲日戊岁入口；其中前五盘本命四柱均不见同柱庚申，但“大运纯制伏”支路未有可执行的来源阈值，所以整体 `有救` 与局部阶梯保持信息不足。`unknown_luck` 另缺所选年有效大运，具名一癸支路也未知。`wrong_day` 和所选 2017 年的 `wrong_year` 不适用。**当前仍没有全章作用的真实正例或反例**；仅具名局部支路有真、假、未知样盘。

运行 `python3 tools/verify-sanming-010-conditional-effect.py` 会核对来源条件阶梯；运行 `python3 tools/verify-sanming-010-l1082-branch-audit.py` 会复核逐字原文、两份点校断句、影印页哈希、50-case 共享夹具及十盘局部投影，并测试缺项、冲突、多癸、跨柱庚申和多年误读。合成边界只验证局部输入政策，不充当全章作用证据。完整 010 的下一步仍是给大运纯制伏支路提供有据可查的输入和有效性标准，解释 L1086 的无庚辛／金局制木／火局焚木条件，裁定 L1087 与 L9697 的定值及优先次序，并补足全章作用真盘正、反、未知验收。在此之前不得把本合同升格到 `rescue_condition`、`transit_effect_semantics` 或主题规则。
