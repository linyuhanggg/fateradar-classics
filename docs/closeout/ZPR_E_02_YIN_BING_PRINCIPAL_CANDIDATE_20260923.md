# ZPR-E-02 寅月丙独透的局部主入口候选（2026-09-23）

**结论**：`《子平真诠》` [L419](../../sources/fulltext/bazi/ziping-zhenquan/fulltext.md#L419) 明说寅月甲为本主，而「不透甲而透丙」时丙得以作主。这足以支持一条**局部月令入口**的窄条件，却不支持把凡见寅中甲的盘都判为正官主格，或从丙入口直接推出最终格局、顺用成效、喜忌、救应。本候选的机器边界见 [JSON](./ZPR_E_02_YIN_BING_PRINCIPAL_CANDIDATE_20260923.json)，运行 `python3 tools/verify-zpr-e-02-yin-bing-principal.py` 可复算；尚未登记 FactKey、正式 P1 清单或改动 ZPR-E-02 本体。

## 原文所能确定的两层结论

- [L328、L340](../../sources/fulltext/bazi/ziping-zhenquan/fulltext.md#L328)要求从月令起，再逐柱参配。L419 的寅藏顺序是甲本主、丙、戊；其条件句只给出**甲不透、丙透 → 丙得以作主**，没有说甲丙兼透时丙不可能为主，也没有给出丙戊兼透时的主兼优先级。
- 因此 JSON 分别记录 `premiseState`（L419 字面前件是否出现）与 `localPrincipalStem`（在可安全消费的清楚形态才给丙）。`premiseState=不满足` 只否定这条**充分条件**，绝不构成「丙不是主格」或整条 ZPR-E-02 的反例。日干只用于后续十神分类；选择月令丙这一干本身不等于已证明正印、偏印等格局作用。
- 本候选要求本命月支与月令同为寅、月藏干完整且恰为甲丙戊，并核年、月、时三个透干位。只有丙一个**月藏干**透出，且完整四柱输入、日干非甲乙时，才产出局部 `丙`。其他非月藏干可同现。丙戊兼透虽满足 L419 字面前件，仍因 [L548](../../sources/fulltext/bazi/ziping-zhenquan/fulltext.md#L548) 的「兼透兼用」保持局部主次未知；甲丙兼透使前件为假，但不能倒推出甲最终为主。[L349–351](../../sources/fulltext/bazi/ziping-zhenquan/fulltext.md#L349)对木日寅月又有禄劫另取程序，先后缺独立裁定，所以不在甲乙日输出本候选的局部主干。这是保守的**消费门槛**，不宣称原文只允许非木日适用。
- [L421](../../sources/fulltext/bazi/ziping-zhenquan/fulltext.md#L421)还表明会支可使原始官入口化印；[L542、L548](../../sources/fulltext/bazi/ziping-zhenquan/fulltext.md#L542)要求透干会支取清、兼透兼用。本候选不扫描出最终格局与会支作用，故即使局部 `丙` 成立，`finalPrincipalStem` 一律信息不足，不能把 `geju.name`、`geju.mode` 或旧正官标签作为古籍独立裁决。

## Product 消费与尚待裁决

Product 可在完整本命盘上把 1969 这类清楚形态的**入口选择**纠为丙，保留原始寅藏甲入口作为被变用的来源线索，并把成败、作用、救应和最终主兼格继续留待核。它应把 `caseB` 与丙戊兼透盘保留为多入口未决，不能把本候选的 `premiseState=不满足` 转成「正官格／正印格不成立」。候选没有正式 FactKey，不应进入 P1 规则评估或六主题确定性结论。
