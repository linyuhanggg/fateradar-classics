# 《六壬指南注解》局部运行来源核对

本批只直接核对当前电子本L151–154与L741的涉害注解，不代表全书白话或占例已经完成。

L151–154明确阴阳比用仍有多候选时称涉害，先取地盘四孟所乘，无孟才取四仲，并特别强调《指南》以孟仲季为准、不以历数深浅为义。L741又说明涉害、比用复等时刚取日比、柔取辰比。二者作为LRZY-E-01独立来源，不合入《大全·订讹》的沿途数克规则。

产品当前`mengzhong`分支与这组取法对应，输出候选所落地盘及孟、仲、季层次；不制造未执行的深浅计数。同一个丁卯亥将丑时输入，孟仲取丑亥酉，大全深浅取亥酉未，均保存所用方法与实际来源，不投票合成。
