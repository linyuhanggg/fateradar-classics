## 3. 官煞并出取清后取运（`L1357-L1357`）

前置：原局「禄劫而官煞竞出，必须取清方为贵格」（`L1331-L1331` / MING-347 `JL-PAR-01`、`JL-SAVE-06`）。本段给**已取清**后的运配；「不论合煞留官，存官制煞」表示两条取清路径共用同一运表。

### 3.1 路径门闩

| 条件 ID | 类型 | 条件 | 锚点 |
|---|---|---|---|
| JL-YUN-CLR-00 | 必要 | 官煞并出，且已完成取清（合煞留官 **或** 存官制煞） | `L1357-L1357`；成清手段例见 `L1331-L1331` |
| JL-YUN-CLR-00b | 边界 | 原文用「存官制煞」，成格章用「制煞留官」——本包视为同义路径标签，**不**另立第三取清术 | `L1357` vs `L1331` |
| JL-YUN-CLR-00c | 排除倾向 | 未取清的官煞并出，不得套用本运表称贵运已配好 | `L1331`「必须取清」+ `L1357` 前置 |

「两官竞出须制伏」（`L1331`）是否完全等同「存官制煞」运表：**未在本段重述** → 见未知项。

### 3.2 取清后运喜忌

| 条件 ID | 类型 | 条件 | 锚点 |
|---|---|---|---|
| JL-YUN-CLR-01 | 喜 | 运喜伤食 | `L1357-L1357` |
| JL-YUN-CLR-02 | 喜 | 比劫亦宜 | `L1357-L1357` |
| JL-YUN-CLR-03 | 非福 | 印绶未为良图 | `L1357-L1357` |
| JL-YUN-CLR-04 | 非福 | 财官亦非福运 | `L1357-L1357` |

留官之后仍写「财官亦非福运」：指**岁运再逢财官**非福，不是否定命中已留之官。算法不得解释成「取清后应去掉原局官星」。
