## 精神、月令、衰旺的定点复核

- PDF 167（印页一二五）：任氏定义确为“精者生我之神也，神者克我之物也”。PDF 169（印页一二七）的丙寅日例却明说“以戊土为神”。这是同版本语义范围不同，不把丙生戊篡改成戊克丙；分别在L3012与L3057注释说明。
- PDF 171（印页一二九）：已核司令出见“可置弗论”以及“地衰门旺／门旺地衰”两句。文字在影印中亦如此，不因为解释费力擅加不字或换词；本次不标整页校定。
- PDF 175（印页一三三）：原注可见“旺之极者不可损”“衰之极者不可益”，用于解释电子L3201错乱句。只核列出的句子。
- PDF 176（印页一三四）：已核L3203根气清单。墓：甲乙未、丙丁戌、庚辛丑、壬癸辰；余气：丙丁未、甲乙辰、庚辛戌、壬癸丑。电子将墓库尾部误复制进第一遍“余气者”，随后又有完整余气清单，不能当两套流派规则。
- PDF 177（印页一三五）：已核“土旺极者而似金，喜火之炼也”。电子L3203作“似水”，L3441例文仍作“似金”；本次以影印字形在notes并列纠错，不覆盖原电子段落。
- PDF 178（印页一三六）：已读衰极条目续行及甲辰／丁卯／甲子／戊辰例的对应关系，未标其余全页逐字校定。
- PDF 179（印页一三七）：上例癸卯／乙卯／甲寅／乙亥与电子四柱一致。影印叙述作“七木两水”，电子作“六木两水”；按八个字表层确为六木两水。因此影印也是待评判的证据，不能用它的字数直接覆盖盘面计数。下例乙丑／甲申／甲申／辛未也已定位。

## 清浊真假与寒暖隐显的定点复核

- PDF 239、241为浊气定位，已对见L5368及L5410/L5430两例版面；仅定位不标全页已校。
- PDF 243（印页一〇一）：L5458电子三式段脱漏。影印列地纪为提纲定格、人纪为人元司令、天纪为天元发露辅格。只核这三个项目，未扩成另一个独立术式。
- PDF 245（印页一〇三）：L5538原注影印作“其人虽无大祸”，电子误作“其人难无大祸”，意义相反。正文注释不采用电子的必有大祸理解。
- PDF 246（印页一〇四）：原版确有“日主爱假憎真，必须岁运扶真抑假，亦可发福；若岁运助真损假，凶祸立至”。扶抑两句的命名视角是否转换未明；矛盾并非可归咎新电子OCR的单字问题，暂保留，不能同时作为两条执行规则，更不能无证据倒改成“扶假抑真”。
- PDF 253–273制作缩略接触页，仅用于寻找顺逆、寒暖、燥湿、隐显、众寡、震兑、坎离的具体位置；缩略浏览不等同整页逐字校定。
- PDF 257（印页一一五）：L5838寒暖任注缺句，影印可读“若寒甚而暖无气，暖至而寒无根，必无生成之妙；是以过于寒者，反以无暖为美，过于暖者，反以无寒为宜”。注释保留有根调候与极势无根两类条件，不凭漏句把所有寒局都补火。
- PDF 258（印页一一六）：L5889己酉／丙子／庚辰／甲申例，影印明确“反以无暖为美”，电子漏无，导致喜忌方向相反。该页上例甲申／丙子／庚辰／戊寅也对到，寅时给木火根是两例差别。
- PDF 264（印页一二二）：隐显首例大运列清楚印有庚午、己巳、戊辰、丁卯，电子L6049“戊圾”应作戊辰。四柱末柱与运列在电子粘连，本段仍是同一运表第三项，不另起段义；原文保持不覆盖。

## 六亲开篇与何知章的定点复核

- PDF 276：只用于坎离末页与卷三起点定位，不标全文已校。
- PDF 278（卷三印页二）：夫妻任注明确“生我者为父母，偏正印绶是也”；电子L6442误为偏正财星。连同我生食伤为子女、我克财为妇妾等原字已核。任氏对财父之说的反对不得被误字抹成又采用财父。
- PDF 280（卷三印页四）：丁未／乙巳／丁酉／癸卯例可读“又得妻财万余”，电子L6512省妻字并改金额表述；只并列来源差异，不添加现代家庭资产。
- PDF 282–283（卷三印页六、七）：已对见任氏改用食伤子女的主要论证及若干强弱印食分支；电子L6540多处整句残缺（如“日主旺，印必无”）不可单独成规则。原文关于制约过多生身之物、间接生食伤的说明并非把官杀直接永远改作子女主星。
- PDF 284（卷三印页八）：戊戌日例的“不敢定其数目”与当事人自述十六子均在；其下丁酉日例明确“妻生八女，妾生八女，竟无子”。电子L6612“妾生入女，竟儿子”讹漏已说明。“无子”此处为无儿子，不是无任何孩子，更不是医学不孕诊断。
- PDF 299（卷三印页二三）：L7041明确印“立夏前五日”，其表仍乙巳／辛巳／庚辰／甲申。与以立夏起巳月的现代排盘口径有冲突，不把它当节令金标准；维持仅四柱关系可复算。
- PDF 301、303只定位何知贫的相邻例文，不标整页逐字校定。
- PDF 305（卷三印页二九）：L7218对应句为“如财重身轻，不以比劫帮身，反忌比劫夺财”，电子“反以”失去批评误忌的语义。已据原句解释，不扩成比劫必夺财规则。
