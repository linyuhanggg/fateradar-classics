# 命理約言 158 个 partial 页的**阻塞项逐页拆解**（本轮实测）

> 数据源：`sources/normalized/bazi/mingli-yueyan/page-reviews.json`（185 页 = 27 `source-reviewed` + **158 `partial`**）。
> 本文件**不提升任何页状态、不改任何转录**；产出是一张可重跑的阻塞项去向表。
> 上游结论：`docs/closeout/B1b-OCR-TRANSCRIPTION-BATCH.md` §4.2 把 158 页的阻塞点归为
> 「黑底项目符号/序号」一类；`partial-blocker-review-001-030.md`（t16）进一步证明**前 30 页内
> 该阻塞物不是「黑底字」而是不含字形的装饰方块**。本轮把它从 30 页扩到**全部 158 页**并给出数字。

## 1. 拆解结果（本轮实测）

按 `unresolved` 逐条分类（符号类判据：`项目｜標｜版面标记｜装饰｜黑底｜符号`——刻意取宽，理由见 §1 末）：

| 类 | 页数 | 含义 |
| --- | ---: | --- |
| A 仅「版面符号/序号未释读」 | **155** | 正文已在 `reviewedRanges` 内逐句对图；唯一未决项是装饰性版面符号 |
| B 符号类 **+** 另有非符号项 | **1**（p30） | 正文工序之外**确有一条实质待核**，见 §3 |
| C 无符号项 | **2**（p1、p2） | 页外材料（封面题字／库内手写号），见 §4 |

**158 = 155 + 1 + 2。** 158 页 `unresolved` 条目合计 159 条：**156 条是符号类，3 条不是**（p1、p2、p30 各一条）。
也就是说：**这 158 页里没有一页是因为「正文没读、字没认、句子没对」而 partial 的。**

> **判据为什么取这么宽（`项目｜標｜版面标记｜装饰｜黑底｜符号`）、以及我是怎么发现该取宽的**：
> p38–43 的措辞是「版面项目**标記**」——**简繁混写**（简「标」＋繁「記」）。第一版正则只列了
> 「标记」「標記」两种完整写法，于是这 6 页被误算进「无符号项」，得出 A=149/B=1/C=8 的错数；
> 扩大英文别名集合两次仍漏，最后改为**按语义词根取宽**（凡带「项目／標／版面标记／装饰／黑底／符号」
> 即视为符号类），才稳定归位为 A=155/B=1/C=2。
> **这正是「先量后判」要防的错**：同一件事的多种字形写法会让分类器**静默漏项**，
> 而漏项的方向恰好是「把已完成的算成未完成」。取宽之后，三条非符号项被逐条打印出来人工确认——
> 宁可多打印三行让人看，也不要让分类器替人决定什么算阻塞。

## 2. 那 156 页（A+B）上未决的到底是什么

`page-reviews.json` 里共 14 种 `unresolved` 措辞，其中 12 种是符号类（分布在 A+B 的 156 页上）。原文举例如下（照录）：

- 「版面项目符号未释读；仅 reviewedRanges 正文可引用」（120 页）
- 「版面项目标记未释读；仅 reviewedRanges 主体可引用」（8 页）
- 「版面项目标記未释字；只开放 reviewedRanges 内正文」（6 页）
- 「黑底项目符号不作正文，其内部字形未录」（5 页）
- 「黑底排版标记未转写；已核主体正文通过 reviewedRanges 单独开放」（5 页）
- 其余 7 种各 1–4 页（装饰项目符号未释读／黑底项目序号未释读…）

t16 已用像素级复核证明前 30 页内的该标记是**实心黑方块＋白心孔洞、白心内无笔画结构**，
功能是节首标记（如「■偏官」＝标记＋偏官格）。**「未释读」是准确的措辞**——但它是**预期不可释读**，
不是缺工序：一个不含字形的装饰方块，无论读多少页都不会读出字来。

## 3. 唯一的例外：p30

p30 有两个未决项：一条是符号类，另一条是**实质语义/版式问题**：

> 表中分量与日数的对应含义、卯/申一钱的版式归属仍待细核；正文与表的三十一/三十差异不擅校

这是**真实待核**（表内数字与日数的对应、以及「三十一 vs 三十」的差异不敢擅改）。
它需要的是**逐格核对那张表**，而不是读装饰符号。本轮不处理，如实登记。

## 4. 另有两页是「页外材料」，不影响正文（C 类）

| 页 | 未决项 | 性质 |
| --- | --- | --- |
| 1 | 封面题名缺字；印文未释读，**不影响正文** | 封面/篆印：非理论正文，属馆藏描述 |
| 2 | 页外手写分类号未逐字释读，**不影响序文** | 页外手写：非印刷正文 |

两页的未决项在记录里已明写「不影响正文／序文」，且都不在 `reviewedRanges` 覆盖的正文范围内。

## 5. 这份拆解改变了什么（以及没改变什么）

**改变了**：
- 158 页的阻塞项从「一类（黑底符号）」变成**逐页可核的三类，且 156 : 1 : 2**（符号类 156 页／实质待核 1 页／页外材料 2 页）；
- 「这批页还需多少正文工序」的答案变得明确：**除了 p30 的一张表，正文工序已为 0**；p1/p2 的未决项在记录里已明写不影响正文；
- 悬着的 158 页不再是一个含糊的「待办块」，而是 156 页的**政策决定**＋ 1 页的**具体核对任务**（p30）＋ 2 页的**元数据记录**（p1/p2）。

**没有改变**：
- **不提升任何页状态**。`source_paragraphs.py` 的门槛是「整页 `source-reviewed` 且无 unresolved」，
  156 页都还带一条 unresolved 行，故仍走 `reviewedRanges` 通道（正文可引用、不开放整页）。
  是否把「装饰符号未释读」视为可放行的未决项，是**引用政策问题**（口径要一致，不能只为这 156 页松绑），
  本轮不擅自决定、也不改计数器。
- 不改 `page-reviews.json`、不改转录文本、不升任何注解 `review` 状态。
- 158 这个数本身**依旧为真**（与 `partial-blocker-review-001-030.md` 的核对一致）。

## 6. 复算方法（可重跑）

```python
import json, re
d = json.load(open("sources/normalized/bazi/mingli-yueyan/page-reviews.json"))
SYMBOL = re.compile(r"项目|標|版面标记|装饰|黑底|符号")
for p in [x for x in d["pages"] if x.get("status") == "partial"]:
    sym = [u for u in p["unresolved"] if SYMBOL.search(u)]
    rest = [u for u in p["unresolved"] if not SYMBOL.search(u)]
    print(p["pdfPage"], "symbol" if sym else "-", "other" if rest else "-", rest)
```

实测输出：155 页仅符号类（A）、p30 为符号＋非符号（B）、p1 与 p2 为非符号（C）。
分类器一旦取宽，非符号项就只剩 3 条，可逐条人读——这就是取宽的目的。
