## 本批诚实结论（先读这一节）

**这一批的性质与 079–090 批完全不同，必须先说清，否则会被误读为「转写完成」。**

1. **280–298 不是连续正文，而是卷八局式区**：圆图与逐时表交替排布，另有 6 页**根本不是《奇門遁甲統宗》正文**（见第 3 条）。
2. **本批的交付层级分三等，逐页标明，不含糊**：
   - **A 级（版面事实 + 标题级登记，可复现）**：280、281、282、292、297、298。
   - **B 级（版面事实 + 标题级登记，正文逐格未读）**：283、284、285、286、287、288、289、290、291。
   - **C 级（非本书正文，只登记其性质）**：293、294、295、296。
3. **重大发现：292–297 不是《奇門遁甲統宗》的正文页，而是出版方插入的广告与书讯页。**其中 293–296 为**上海文明書局**自身之「各 種 尺 牘／商 業 用 書／現代論丈彙刊」等**图书广告**（详见各页 `page_type`）。**按「不代填、不臆测」原则，本批不逐行转写广告文案**——它们是二十世纪书局的商业材料，不属于本次古籍补缺范围。**此点请队长裁定其归属**。
4. **B 级各页之逐时格（时支 + 门星 + 八门 + 格局断语）本批未逐格转写。**理由是可测的，不是我偷懒：这些页每页只有一个文字块（实测 1400–1440×1200–1800px），却承载**竖排大字行头 + 六列时支 + 每列数十条小字断语**，小字约合 400dpi 下 10–12px/字、700dpi 下约 18–21px/字；我**能**读准大字（时支、门星、宫数），**不能**保证小字断语逐字无误。凡我未达到逐字可担保之处，一律**登记为版面事实并声明未转写**，不填、不猜、不据邻近页推补。

# ② 实测文字块（60 墨迹列阈值）+ 竖排指纹：Xcol>Ychar*1.25 => 竖排（正立）
from PIL import Image
import numpy as np
def fund(v, minlag=8, maxlag=260, thr=0.10):
    v = v - v.mean(); ac = np.correlate(v, v, "full")[len(v)-1:]; ac = ac/ac[0]
    c = [(float(ac[l]), l) for l in range(minlag, min(maxlag, len(ac)-1))
         if ac[l] > ac[l-1] and ac[l] >= ac[l+1] and ac[l] > thr]
    return max(c)[1] if c else None
