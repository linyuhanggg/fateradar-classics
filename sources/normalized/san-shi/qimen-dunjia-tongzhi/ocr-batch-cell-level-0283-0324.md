## 1. 悬案 (a) 结案：九页「指纹异常」的成因

**结论：那九页不是取向问题，也不是字体大小问题；是「多字列（pitch≈510px）与单字列（pitch≈114–120px）在页内并存」，而页级 X 基频取决于哪一族的墨迹在整页轮廓中占优。**

**方法：分带轮廓法（同解释四庫《六壬大全》總鈐页 Y 加倍所用的方法）。** 900dpi 下把每页文字块纵向六等分，逐带测 X／Y 基频：

| --- | --- | --- | --- |
| 283 | 507 | (510,147)(510,150)(509,150)(114,153)(114,150)(117,150) | 否（510 族占前 3 带） |
| 285 | 507 | (507,149)(507,153)(506,150)(507,150)(114,156)(111,151) | 否 |
| 287 | 120 | (510,142)(510,156)(507,147)(114,150)(108,147)(111,153) | **是（后 3 带）** |

| 306 | 120 | (513,153)(510,153)(510,153)(510,153)(118,150)(130,154) | **是** |
| 307 | 120 | (510,143)(510,153)(114,150)(117,150)(117,150)(114,142) | **是** |
| 314 | 123 | (510,144)(510,154)(123,150)(117,150)(114,153)(111,42)† | **是** |

† 带内墨迹过少时基频落在噪声上（42／39／45），**不作结论**。

**关键对照**：283 与 285 两页在 t14 中判为「指纹正常（X=507／UPRIGHT）」，其**逐带剖面由完全相同的 (510…)(114…) 两族构成**——即**「正常页」与「异常页」的内部结构相同**，差别只在两族墨迹占比。故页级 X 的 507↔120 分裂**不携带取向信息、也不携带字号信息**。

**字号反证（直接量测，推翻我自己的「混合字号」猜测）**：同一页 p283 上，
- 「大字行标区」（x2330–2484, y1578–2212）：字高中位数 **107px**
- 「密集断语区」（x3283–3506, y2410–3400）：字高中位数 **107px**

**两处字号相同。** 因此该页是**单一字号（约106px@900dpi）**，先前的「大小字两族」说法**不成立**，此处撤回。

**取向结论**：本区九页**均为正立**，与其余各页无异。理由为**直接的、不依赖指纹的**实测：逐列的**字序自上而下**（字距周期 Y=150px 稳定出现于每一带的每个列），这正是竖排汉文的必要条件；且页内每一列的墨迹在 Y 向呈周期性、在 X 向为列宽约 106px 的条带。**指纹 X 的差异不再作为取向依据（也不曾被用来判定取向）。**

> 本节自我更正两处：① 我曾把 287 等页的 X 异常原因猜测为「可能与块内横排小字行较多有关」——**该猜测错误，且我此前已标注为「猜测、不列为结论」，现予撤回**；② 我曾提出「大小字两族」——**实测同字号，现予撤回**。

## 2. 悬案 (b) 结案：第 324 页 858px 块宽

**结论：858px 是真实块宽，不是扫描裁切，也不是估算错误。** 900dpi 实测本页文字块宽 **1932px**，而邻页为 **3156–3248px**；1932÷2.25 = **859px@400dpi**，与 t14 记录一致（t14 记录为 858px，差 1px 属取整）。

**且本页字号与邻页相同**：字高（Y 字距周期）实测 **150px@900dpi，与 303 等页完全一致**。故本页并非缩印、非异版，而是**版面上实际只排了约一半宽的文字**（本页为卷九局式区末页，余文不足）。

```python
# ① 直接量测字块（glyph run）—— 取代 t14 的「页级数字按比例折算」错误做法
from PIL import Image
import numpy as np
def runs(v, minv, minw=1, maxgap=2):
    out=[]; st=None; gap=0
    for i,x in enumerate(v):
        if x>minv: st=i if st is None else st; gap=0
        else:
            if st is not None:
                gap+=1
                if gap>maxgap:
                    if i-gap-st>=minw: out.append((st,i-gap))
                    st=None; gap=0
    if st is not None and len(v)-st>=minw: out.append((st,len(v)))
    return out
im=Image.open('/tmp/qm-t17/render900/pg-283.png').convert('L')
ink=np.asarray(im)<140
# 断语区样例（x3283-3506, y2410-3400）
sub=ink[2410:3400, 3283:3506]
gl=[(a,b) for a,b in runs(sub.sum(1),0,20,3)]
hs=[b-a for a,b in gl]; c=[(a+b)/2 for a,b in gl]
d=[c[i+1]-c[i] for i in range(len(c)-1) if c[i+1]-c[i]<300]
print('glyphs',len(gl),'h_median',int(np.median(hs)),'pitch_median',int(np.median(d)))
# -> glyphs 7 h_median 107 pitch_median 150     (即 106-107 px/char @900dpi)
```

```python
def fund(v, minlag, maxlag, thr=0.10):
    v = v - v.mean(); ac = np.correlate(v, v, "full")[len(v)-1:]; ac = ac/ac[0]

       if ac[l]>ac[l-1] and ac[l]>=ac[l+1] and ac[l]>thr]
```
